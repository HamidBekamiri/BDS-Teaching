3

How AI-LAB works, in one minute

Front endWhere you log in. No GPU: edit files, copy data, submit jobs. Do not run heavy work here.
SlurmGives you a GPU node. srun = interactive, under an hour. sbatch = a job that runs on its own, up to 12 hours, even when your laptop is closed.
ContainersSoftware comes in Singularity containers. Ready ones are in /ceph/container; you can pull others, such as Ollama.

Limits: 1 hour if you set no time, at most 12 hours per job; at most 4 GPUs per job and 8 per user; 24 GB memory and 15 CPUs per GPU. Ask for 1 GPU: reserving GPUs you do not use breaks the fair-usage policy.

4

Set up Ollama and Python (once, on AI-LAB)

Run these on AI-LAB, after logging in. Each takes a few minutes.

Download the Ollama container into your home folder
srun --mem=40G --time=00:30:00 singularity pull ollama.sif docker://ollama/ollama:latest
Install the Python packages the extraction needs
srun --time=00:15:00 singularity exec /ceph/container/python/python_3.10.sif pip install --user openai pydantic pandas
Test: open a shell on a GPU node, inside the container
srun --gres=gpu:1 --mem=24G --time=00:30:00 --pty singularity shell --nv ollama.sif
Inside that shell: start Ollama, download the model (about 7 GB, once) and ask it something
export OLLAMA_MODELS=$HOME/ollama-models
ollama serve > ollama.log 2>&1 &
sleep 10
ollama run gemma4:e2b "Say ready"
exit

If it answers, the GPU, the container and the model work. exit gives the GPU back.

6

Run the extraction as a job

On AI-LAB: submit the job
sbatch run_extract.sh

Slurm answers Submitted batch job 12345. Now you can log out and close your laptop: the job runs on its own.

Follow it
squeue --me                 # is it waiting (PD) or running (R)?
tail -f extract_*.out        # progress, e.g. "250/669 done" (Ctrl+C to stop watching)
wc -l facts.jsonl            # how many papers are done
scancel 12345                # stop the job, if you need to

If the job stops (time limit, error), just run sbatch run_extract.sh again: it skips the papers already in facts.jsonl. Errors go to extract_*.err and ollama_*.log.

The two job files

Same form and same ask() as in the workshop notebook, so the results fit straight into it.

extract.py
"""Extract research question, data, theories, methods, findings and results from abstracts with a local LLM.

Input : papers_to_extract.csv with the columns eid and text ("Title. Abstract"), made in the workshop notebook.
Output: facts.jsonl, one line per paper. Run it again and it continues where it stopped.
Needs : an Ollama server on this machine (see run_extract.sh) and: pip install --user openai pydantic pandas
"""
import json
import os
from concurrent.futures import ThreadPoolExecutor
from typing import List, Literal

import pandas as pd
from openai import OpenAI
from pydantic import BaseModel, Field

MODEL = os.environ.get("MODEL", "gemma4:e2b")
INPUT, CACHE = "papers_to_extract.csv", "facts.jsonl"
HOST = os.environ.get("OLLAMA_HOST", "127.0.0.1:11434")      # run_extract.sh gives each job its own port
client = OpenAI(base_url=f"http://{HOST}/v1", api_key="ollama", timeout=120)

DATA_TYPES = {
    "survey": "questionnaires answered by people",
    "interviews": "interviews, focus groups or workshops",
    "experiment": "a controlled experiment or user study",
    "text/documents": "texts, posts, reviews, reports as data",
    "firm or market data": "company, financial, market or administrative records",
    "literature": "published studies, as in a review or bibliometric study",
    "llm outputs": "answers generated by an LLM are the data",
    "none/conceptual": "no data: theory, framework or argument",
    "other": "anything else",
}
RELATIONS = ["INCREASES", "DECREASES", "NO_EFFECT_ON", "MODERATES", "MEDIATES", "ASSOCIATED_WITH"]


class Finding(BaseModel):
    cause: str = Field(max_length=50, description="a construct in 1-4 words, lower case, e.g. 'perceived usefulness'")
    relation: Literal[tuple(RELATIONS)]
    effect: str = Field(max_length=50, description="a construct in 1-4 words, lower case, e.g. 'continuance intention'")


class PaperFacts(BaseModel):
    research_question: str = Field(description="the question or aim of the paper, one sentence")
    data: str = Field(description="the data in your own words, with size and source if given; 'none' if none")
    data_type: Literal[tuple(DATA_TYPES)]
    results: str = Field(description="the main finding, one sentence")
    theories: List[str] = Field(description="0-3 theories or frameworks the paper builds on, e.g. 'UTAUT'")
    findings: List[Finding] = Field(description="0-3 tested relationships the abstract reports as results")
    methods: List[str] = Field(description="1-4 analysis techniques, short standard names, e.g. 'PLS-SEM'")


SYSTEM = ("Read the abstract of a scientific paper and fill in the form. Use only what the abstract says.\n"
          "methods: the techniques used to analyse the data, at most 4, short standard names (e.g. 'PLS-SEM', "
          "'fsQCA', 'thematic analysis', 'experiment'). Not theories, not software, not the data source.\n"
          "theories: named theories or models such as TAM, UTAUT, S-O-R; empty if none.\n"
          "findings: only relationships the abstract reports as tested results, at most 3; empty if none. "
          "cause and effect are constructs (variables) in 1-4 words, written out in full, not sentences and not "
          "acronyms, e.g. 'trust' INCREASES 'purchase intention'.\n"
          "data: describe the data itself; do not repeat the data_type category.\ndata_type:\n"
          + "".join(f"- {k}: {v}\n" for k, v in DATA_TYPES.items()))


def ask(system, user, schema, max_tokens=900):
    """One structured answer. A cut-off answer often only misses its closing brackets, so add them and check."""
    form = {"type": "json_schema", "json_schema": {"name": schema.__name__, "schema": schema.model_json_schema()}}
    for temperature in (0, 0.3, 0.6):
        r = client.chat.completions.create(
            model=MODEL, temperature=temperature, max_tokens=max_tokens, response_format=form,
            messages=[{"role": "system", "content": system}, {"role": "user", "content": user}],
            reasoning_effort="none")
        text = (r.choices[0].message.content or "").rstrip().rstrip(",")
        for ending in ("", "}", "]}", '"]}', "}]}", '"}]}'):
            try:
                return schema.model_validate_json(text + ending)
            except Exception:
                pass
    raise ValueError(f"no valid answer after 3 tries: {text[:200]}")


def extract(row):
    try:
        return {"eid": row.eid, **ask(SYSTEM, row.text, PaperFacts).model_dump()}
    except Exception as e:
        return {"eid": row.eid, "error": str(e)[:200]}


if __name__ == "__main__":
    papers = pd.read_csv(INPUT)
    done = {json.loads(line)["eid"] for line in open(CACHE)} if os.path.exists(CACHE) else set()
    todo = papers[~papers.eid.isin(done)]
    print(f"{len(papers)} papers · {len(done)} done · {len(todo)} to do · model {MODEL}", flush=True)
    with ThreadPoolExecutor(4) as pool, open(CACHE, "a") as f:
        for i, out in enumerate(pool.map(extract, todo.itertuples()), 1):
            f.write(json.dumps(out) + "\n")
            f.flush()
            if i % 25 == 0 or i == len(todo):
                print(f"{i}/{len(todo)} done", flush=True)
    print("finished: facts.jsonl", flush=True)
run_extract.sh
#!/bin/bash
#SBATCH --job-name=extract
#SBATCH --output=extract_%j.out
#SBATCH --error=extract_%j.err
#SBATCH --gres=gpu:1
#SBATCH --mem=24G
#SBATCH --cpus-per-task=8
#SBATCH --time=06:00:00

# Ollama in its own container, on a port of its own (other jobs may share the node)
export OLLAMA_HOST=127.0.0.1:$((20000 + SLURM_JOB_ID % 10000))
export OLLAMA_MODELS=$HOME/ollama-models
export OLLAMA_NUM_PARALLEL=4
singularity exec --nv ~/ollama.sif ollama serve > ollama_$SLURM_JOB_ID.log 2>&1 &

# wait until the server answers, then download the model (only the first time)
for i in $(seq 60); do singularity exec ~/ollama.sif ollama list > /dev/null 2>&1 && break; sleep 2; done
singularity exec ~/ollama.sif ollama pull gemma4:e2b

# the extraction; facts.jsonl grows as it goes
singularity exec /ceph/container/python/python_3.10.sif python3 extract.py
